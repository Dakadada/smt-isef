## API
1. **Labels** — `LabelState` {measured_positive, verified_negative, unlabeled, unassayed, censored}; `validate_table(rows, responder_only_studies=())` -> `ObservationTable`. Required: observation_id (unique), label_state, assay_id, study_id, independent_unit_id, provenance (str or mapping with `source`). `verified_negative` needs `negative_evidence` with `assayed_and_powered is True` (identity, not truthy) + finite `detection_limit`; rejected outright if `source_table_kind` is responder-only, the study is in `responder_only_studies`, or `basis` is absence-inferred (`NegativeEvidenceError`). Any `binary_label`/`label`/`y`=0 on a non-verified-negative row raises `LabelStateError`. `read_table(.jsonl/.json)`.
2. **Splits** — `GroupingConfig` (edit|hamming threshold, default edit<=2; containment = identical so F14/F10 cluster with F18; `window_padding`; `strand_aware`; `relax`). `axis_groups` gives per-row ids on 4 axes: sequence (single-linkage), chemistry, study, window (interval sweep, 1-based closed). `make_splits(rows, mode, seed, n_folds, min_independent_groups=3)`, modes `leave_one_aso_out | leave_study_out | region_blocked`: test = one primary-axis unit; every other row sharing ANY active-axis group with a test row is **purged** (neither side). `n_folds=k` = seeded k-fold over connected components. `make_nested_splits(outer_mode, inner_mode, ...)`: inner folds built only from outer-train rows. `SplitRefused` states independent N and the minimum; `verify_no_leakage` re-checks every plan (`LeakageError`).
3. **Metrics** — `compute_metric(name, rows, scores, policy=MetricPolicy(10, 10), threshold, mode, negative_states)`: auroc, auprc, accuracy, precision, recall, fdr, brier, calibration_error (+aliases), `precision_recall_curve`. Minimums count distinct `independent_unit_id` per class, not rows; else `MetricBlocked(.metric, .reason)`. `negative_states` other than exactly verified_negative -> `LabelStateError`. Ties: mid-rank AUROC, tie-grouped AP. `pu_report(rows, scores, top_k, class_prior, min_positives)` -> `PUQuantity`s (`pu_recall_at_top_k` with expected credit for ties at the cut, positive mean/median percentile rank, `pu_positive_vs_unlabeled_rank_probability`, and — only with a stated prior — `pu_prior_adjusted_rank_probability` tagged `model_assumption`, SCAR); each carries `evidence_class` + `pu_assumption`. `mode="pu"` on `compute_metric` always raises.
4. **Uncertainty** — `effective_clusters` = `independent_unit_id` merged with sequence + window clusters (overlapping windows under different unit ids are one cluster); `cluster_bootstrap_ci(rows, statistic(indices), n_boot, seed, min_clusters=10, merge_axes)` percentile CI, `UncertaintyRefused` below min clusters or when >10% replicates are degenerate; `bootstrap_metric_ci` (point estimate must pass the full guard).
5. **Baselines** — `BASELINES` M0 (seeded permuted reference, no features), M1..M5 cumulative families complementarity(derived)/duplex(model_assumption)/accessibility(proxy)/splice_geometry(derived)/sequence_ablation_proxy(proxy) mapped to J9 `feature_name`s (test asserts each name exists in `j9_smn2_prediction.py`); `register_baseline`. `run_ablation(rows, features, baseline, plan, fit_predict, pu=..., source_paths=...)` -> `AblationResult` of `AblationCell`s (variant full / drop:<family>, per-fold `test_group_ids`, `held_out_groups`, metrics, `blocked` name->reason) plus pooled out-of-fold cells. Test records passed to `fit_predict` carry no label. The module itself trains nothing.
6. **Forbidden sources** — `check_source_not_forbidden` (literal, URL-decoded, normalised, symlink-resolved) refuses `SMN2_Exon7_7_27+28_Complete_Data*`, any `psi25` path component, `feng/terminal`; applied in `read_table`, to every provenance string / `source_path` in `validate_table`, and to `run_ablation(source_paths=...)`.

## Open questions / caveats
1. **M6 is undefined upstream** (J9 stops at M5). It is registered as `kind="undefined"` and raises `BaselineUndefined` until someone calls `register_baseline`. What is M6 meant to add (J6 off-target burden?)
2. **Default-strict grouping will refuse most real ASO sets**: chemistry family and study are keep-together axes by default, so a single-chemistry or single-study table has independent N = 1. Proceeding requires an explicit `GroupingConfig(relax=(...))`, recorded as `relaxed_axes` on the plan. Confirm this default, and the thresholds (edit<=2, padding 0, min groups 3, min 10 neg/10 pos units, min 10 clusters) — all are my choices, none came from the brief.
3. The forbidden-source guard only sees paths it is handed: `run_ablation` takes in-memory rows/features, so a caller who loads a file elsewhere and omits `source_paths`/provenance bypasses it. A positive allowlist (J9 style) would be stronger.
4. `chemistry_family` is a free-text exact match (case-insensitive); there is no ontology, so "MOE" vs "2'-MOE" would not group. Sequence clustering is O(unique^2), capped at 4000 unique sequences.
5. Pooled out-of-fold cells mix scores from different per-fold models (flagged in `pooled_note`). A single-family baseline (M1) yields a `drop:` variant with zero columns. PU `class_prior` is a stated input, never estimated. No parquet reader (J9/J3 tables must be pivoted to `{observation_id: {column: value}}` by the caller); not exercised against the real J9 `features.parquet`.
